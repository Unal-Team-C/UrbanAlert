# UrbanAlert
Urban Alert es una plataforma de reportes georeferenciados que permite a los ciudadanos registrar daños en la infraestructura urbana, como vías, semáforos, señalización y alumbrado. La información recolectada se centraliza en un mapa para facilitar la identificación, seguimiento y atención oportuna de la afectación por parte de los entes gubernamentales responsables.
